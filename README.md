# Emoji Blasters

Asteroids, but everything is an emoji. A 🚀 against waves of 🪨 🍩 🥔 🐙 🎃
that split when shot, 🛸/👾 saucers that shoot back, 🛡️ ⚡ ❤️ power-ups,
hyperspace, synth sound, and touch controls. One `index.html`, no build, no
dependencies.

Live at **https://emoji.lab980.com** once provisioned.

- Play locally: open `index.html` in a browser.
- Keyboard: `← →` / `A D` rotate · `↑` / `W` thrust · `Space` fire ·
  `Shift` / `H` hyperspace · `P` pause · `M` mute · `Enter` start.
- Touch: on-screen buttons appear on coarse-pointer devices.

How changes land and how the site deploys: `CLAUDE.md` and `DEPLOY.md`.
